0run / The stack
Technologies

Verifiable by default.

01

0G Chain

Ownership

The coach is an ERC-7857-style intelligent NFT (OrunAgentNFT) on Galileo. Every memory update is hash-anchored in CoachRegistry. Each coach is also registered on the live ERC-8004 IdentityRegistry.

02

0G Storage

Privacy

Runs are AES-256-GCM encrypted with a key derived from the runner's wallet signature — never persisted — then stored on 0G Storage with the SDK's own encryption on top.

03

0G Compute

Verifiable AI

All coach reasoning runs on 0G Compute, billed on-chain. Effort scores run on a TEE provider with per-response cryptographic attestation; every response carries an x_0g_trace proof of use.

04

ENS

Identity & agent-to-agent

Coaches don't just have names — they talk to each other. Each one is a live-resolved subname (pedro.0run.eth) and consults its peers via the agent-endpoint[a2a] record: EIP-191-signed requests verified against the caller's agent-signer, resolved fresh at request time. ENS is the entire auth layer — no API keys, no hard-coded peers.

05

World

Human-backed agents

One human approval, verified on every consult. The owner authorizes the delegation once in World App — AgentBook registration at mint, QR, gasless relay. Every incoming A2A consult then checks on-chain that a real, unique human backs the calling agent (lookupHuman); no human, no answer. The anonymous humanId meters quotas per human, not per agent.

06

App & infra

Self-hosted

Next.js 16 with Privy embedded wallets (email login, no seed phrase), Postgres as a rebuildable index, Docker on a Hetzner VPS. Images build on the server — no secrets in repo or CI. Push to main → tests → deploy → health-checked rollback.

0run / Tracks
Technology → track

How each technology is actually used.

Track · Best AI Product

0G

  • The product is the track: an AI agent whose identity, memory and reasoning all live on 0G.
  • Chain — coach minted as ERC-7857 iNFT, memory trail anchored per run, ERC-8004 registered.
  • Storage — every run encrypted client-key-first, merkle root computed locally.
  • Compute — all inference on-chain-billed; effort score TEE-attested, not asserted.
  • 0G DA deliberately unused — it serves rollups, not this product.
Track · Agent identity

ENS

  • Every coach is discoverable by name: pedro.0run.eth, resolved live on every render — nothing hard-coded.
  • ENSIP-26 records describe the agent and point to the exact iNFT: chainId:contract:tokenId.
  • ENS as the auth layer: agent-to-agent consults are verified against the caller's agent-signer record, resolved at request time.
Track · AgentKit

World

  • The human authorizes once: a World App approval registers the wallet on AgentBook — QR at mint, gasless relay, no CLI.
  • Every A2A consult verifies the delegation on-chain — lookupHuman on the caller's ENS addr. No human behind the agent, no answer.
  • The anonymous humanId meters quotas — per human, not per agent, so spinning up 50 agents multiplies nothing — and traces abuse to a person, not a throwaway wallet.
